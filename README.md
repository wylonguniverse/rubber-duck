# Rubber Duck Debugger

Расширение для Visual Studio Code: **резиновая утка** в боковой панели, которая не решает проблему за вас, а задаёт вопросы, пока вы сами не найдёте ответ.

## Идея

Метод «резиновой утки» известен в программировании: если объяснить проблему вслух неодушевлённому собеседнику, решение часто находится само. Расширение переносит этот приём прямо в редактор. Утка работает локально, без внешних сервисов и API-ключей.

## Возможности

**Чат с уткой**
- Чат в боковой панели (Activity Bar), история сохраняется при переключении панелей.
- Утка задаёт уточняющие вопросы и подбирает их по ключевым словам вашего сообщения: `undefined`/`null`, циклы, `async`/`await`, массивы и индексы, падения и исключения, нестабильное поведение, «раньше работало».
- Вопросы не повторяются; если подходящих нет, используются общие («Что ты ожидал получить?», «Что получилось на самом деле?»).
- Каждые 6 реплик утка просит пересказать проблему одним предложением.
- Сообщение «понял», «нашёл», «решил» завершает сессию, а «не понял» не считается решением.
- Пока утка «думает», она покачивается, а в чате показывается индикатор набора.

**Работа с кодом в редакторе**
- **Выделенный код.** Выделите фрагмент и нажмите кнопку в панели, команду из палитры или пункт контекстного меню «Объяснить утке выделенный код». Утка подсвечивает строки в редакторе и задаёт вопросы, подобранные под содержимое: функции, циклы, условия, асинхронный код, `try/catch`, пустые значения, длинные фрагменты.
- **Ошибки в файле.** Утка читает диагностику языковых серверов (ошибки и предупреждения активного файла), подсвечивает проблемную строку и спрашивает, почему компилятор недоволен именно здесь. Повторное нажатие переходит к следующей проблеме.
- Подсветка снимается, когда вы начинаете править файл.

**Настройки**
- `rubberDuck.duckName`: имя утки в приветствии (по умолчанию «Кряк»).

## Команды

| Команда | Где доступна |
|---|---|
| `Утка: Начать сессию` | палитра команд (`Cmd/Ctrl + Shift + P`) |
| `Утка: Объяснить утке выделенный код` | палитра, контекстное меню редактора при выделении |
| `Утка: Спросить про ошибки в файле` | палитра, кнопка «Ошибки в файле» в панели |
| `Утка: Новая сессия` | палитра, значок обновления в заголовке панели |

## Установка

### Из готового пакета `.vsix`

1. Скачайте или соберите файл `rubber-duck-<версия>.vsix` (см. ниже).
2. В VS Code откройте вкладку расширений (`Cmd/Ctrl + Shift + X`), нажмите `…` в правом верхнем углу и выберите **Install from VSIX…**.
3. Перезагрузите окно: `Developer: Reload Window`.

### Сборка из исходников

Требуются [Node.js](https://nodejs.org) 18+ и VS Code 1.85+.

```bash
git clone https://github.com/<ваш-логин>/rubber-duck.git
cd rubber-duck
npm install
npm run compile
```

Запуск для разработки: откройте папку в VS Code и нажмите **F5** (или **Run → Start Debugging**). Откроется окно `Extension Development Host` с подключённым расширением.

Сборка установочного пакета:

```bash
npx @vscode/vsce package
```

## Структура проекта

```
rubber-duck/
├── package.json            # манифест: панель, команды, меню, настройки
├── tsconfig.json
├── src/
│   ├── extension.ts        # activate(): регистрация панели и команд
│   ├── duckViewProvider.ts # Webview-панель, обмен сообщениями, история чата
│   ├── editorContext.ts    # выделение, диагностика, подсветка строк
│   └── questionEngine.ts   # правила и подбор вопросов (без зависимости от VS Code)
├── media/
│   ├── chat.js             # логика интерфейса чата в Webview
│   ├── chat.css            # стили (используют цвета темы VS Code)
│   ├── duck.svg            # утка в шапке чата
│   └── duck-icon.svg       # значок в Activity Bar
└── docs/
    └── REPORT.md           # отчёт: архитектура IDE и разработка плагина
```
